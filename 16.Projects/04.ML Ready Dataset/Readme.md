# Project 4 — ML-Ready Dataset

**Goal:** Take a messy dataset and produce a clean, validated, ML-ready table.

**Suggested steps:**
1. Load and inspect.
2. Drop duplicates, fix dtypes, handle missing values.
3. Encode categoricals, scale numerics.
4. Validate with assertions.
5. Export `ml_ready.parquet` (and a schema description).

**Deliverables:** `ml_ready.parquet` + validation report.
